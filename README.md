# Vaults

One Git repo for all Obsidian vaults. Each folder is its own vault.

| Folder | Vault | Status |
|---|---|---|
| `drakma/` | Work (Drakma) | Active |
| `personal/` | Personal | Coming later |

Open a vault in Obsidian with **Open folder as vault** and pick the folder (e.g. `vaults/drakma`), not `vaults/` itself.
