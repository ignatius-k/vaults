# How tasks work

One format everywhere, so Claude can read and update them:

```
- [ ] Task to do 📅 2026-11-14 #qrpe
- [/] Started / partly done
- [ ] ⏳ Waiting on @Person: what you're waiting for
- [x] Finished ✅ 2026-11-11
- [-] Cancelled
```

- **📅 date** = due date (optional).
- **#tag** = project (Claude adds it).
- Tasks live in the **project hub** (e.g. [[QRPe]]). The daily note picks today's few.
- Tick a task anywhere: Claude copies the tick to the hub at its next check.

Optional: install the community plugin **Tasks** for nicer checkboxes and due dates. It isn't required.
